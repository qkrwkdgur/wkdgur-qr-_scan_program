## ✨ 주요 기능 (Key Features)
* **[qr저장]:** 스캔된 qr을 url형식으로 저장
* **[qr삭제]:** 스캔된 qr을 저장기록에서 삭제
* **[qr저장기록 다운로드]:** 저장해둔 qr 스캔 기록을 다운로드
